# 幼儿园社会主义核心价值观课程技能

可迁移版 v1.4.0。帮助教师结合班级资料和可追溯案例，设计、评审幼儿园中班与大班课程，输出可编辑 Word。

## 可以做什么

- 覆盖社会主义核心价值观十二个主题，结合儿童年龄、已有经验、兴趣和真实问题设计活动。
- 按“课程缘起、课程目标、课程脉络、课程实施、儿童发展、教师反思”六部分组织课程。缘起写出生活场景与儿童问题，目标独立成章，脉络保留原稿的一行四格阶段表。
- 实施以连贯叙述为主，二列或三列表格提炼重点；儿童发展对应目标，教师反思说明下一步调整。
- 提供十七份教师材料的分析摘要（十五份 PPT，以及《诚信之花，童心绽放》Word 与周敏版《敬业小达人》PPT 的补充提炼）、三十项趣味活动及评审。活动库含小、中、大班各十项；课程技能当前适用于中班、大班。
- 新增二十份不同 Word 稿件的[框架研究](references/teacher-materials/DOC00-word-framework.md)与[课程写作方法](references/curriculum-framework.md)，取长补短，不把原稿经历移作当前班级实录。
- 按年龄、课程目标和班情选择活动，落实调整要求，标明来源与改编内容。
- 生成 Word，检查字体、标题、缩进、表格、分页和内容完整性。

资料没有真实班情时，输出待校准的建议稿；不编造儿童原话、实施过程或成长结果。活动可按需选择，也可不用游戏。
建议稿也要有具体情境和儿童能够开展的行动，不能把课程缘起写成检查清单。旧版四部分输入需按新版框架整理：目标从缘起单列，补充四格脉络，实施、儿童发展、教师反思顺延为第四至六部分。

## 安装与使用

下载本仓库的完整文件夹，或运行：

```bash
git clone https://github.com/rootliuat/kindergarten-core-values.git
cd kindergarten-core-values
```

将整个文件夹交给所用 AI 工具的技能加载机制；也可以让支持本地文件读取的 Agent 直接读取 `SKILL.md`。请保留子目录。

把下面的指令发给 Agent，并替换方括号中的内容：

```text
读取【请替换成本技能 SKILL.md 的完整路径】，按 references/portability.md 检查环境，按缺项安装技能目录内的文档依赖，已有的不重复安装。缺系统软件或字体时告诉我。运行排版自检并查看渲染结果。
使用本技能设计【请替换成社会主义核心价值观主题】的【请替换成中班或大班】课程。
班情：【请替换成幼儿已有经验、兴趣或真实问题；暂无请写“先做建议稿”】。
教师材料：【请替换成材料文件夹完整路径；暂无请写“使用技能内资料”】。
保存位置：【请替换成输出文件夹完整路径】。
输出可编辑 Word，落实活动评审与调整要求，标明来源和改编，检查格式与分页。
```

## 文档工具

基础环境：Python 3.11 或更高版本、Node.js 22 或更高版本及 npm。渲染检查还需 LibreOffice。

在本文件夹运行（部分系统使用 `python3`）：

```bash
python scripts/setup.py
python scripts/setup.py --install
python scripts/smoke_test.py --out 自检输出
python scripts/test_word.py
```

前三条分别检查环境、按需安装依赖、生成并渲染排版样例；第四条检查六部分与表格生成、错误输入及输出检查器的关键约束。人工或 Agent 仍需查看渲染页面。

Word 标题为方正小标宋简体小二（18 磅）、居中、不加粗；一级标题黑体三号；二级标题楷体_GB2312三号加粗；三级标题仿宋_GB2312三号加粗；正文仿宋_GB2312三号。各级标题与正文首行缩进两字符，段前段后为零，固定行距二十八磅。表头及左栏小标题水平、垂直居中。完整要求见 [Word 输出规范](references/word-output.md)。字体需自行安装。

## 小红书与资料来源

使用已整理的资料无需登录小红书。新增调研时，再按 [xiaohongshu-mcp 官方说明](https://github.com/xpzouying/xiaohongshu-mcp) 配置并登录。仅浏览、检索、阅读和记录来源。

活动质量结合玩法、年龄适宜性、参与机会、材料条件和证据判断；点赞、收藏等互动量仅作背景信息。阅读 [活动选用规则](references/activity-selection.md) 和 [活动库索引](references/games/index.md)。

[教师补充材料索引](references/teacher-materials/index.md)中 T01、T02 可直接作为设计参考，无需先取得原件。引用时写明摘要编号与改编内容。

包内提供摘要、分析和来源记录，不包含原始教师 PPT、Word、调研原图视频、字体、账号或登录凭据。原作者信息与外部来源保留在相应记录中；链接与摘要不表示原作者背书。

## 验证范围

v1.4.0 已通过四项自动回归测试（含六种错误输入）、技能入口校验及 DOCX XML 检查。在 Windows 使用 Microsoft Word 导出八页中班民主建议稿和五页排版样例，逐页检查无文字缺失、遮挡或表格断裂。DOCX 标题字体设置符合规范，但本机 Word 导出的 PDF 标题发生字体替换，实际标题字体一致性尚未通过；不能把 XML 检查通过等同于字体渲染通过。

尚未实测其他电脑或操作系统，也未完成课堂试教。不同模型、输入、字体和办公软件可能影响内容与分页。此前隔离目录依赖安装及九页大班民主样例验证属于旧版记录，不作为新版跨环境验证依据。
