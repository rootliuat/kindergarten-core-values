# 趣味活动的按需选用

用于用户要求增加趣味性，或已有课程确实需要一种可操作的游戏形式时。先明确目标和儿童要解决的问题，再读[活动索引](games/index.md)，只打开相关候选的完整卡。已有教师案例能满足需要时，可保留原活动；不用为了使用活动库而增加环节。

## 先说明为何需要

从已提供的资料确定年龄、已有经验、兴趣或困难、材料、空间与支持需要。缺少班情时给条件性建议，并在方案中写明采用条件；不把假设说成班级事实。

对每个候选回答：“本课要让儿童获得什么经验？这个游戏中的哪一种行动或关系能支持它？”若理由只有热闹、好看、点赞多或可贴上主题标签，就不作为本课核心活动。必要的短时过渡游戏可单列为过渡支持，但不承担主题学习效果的证明。允许不选游戏，不预设每节课或每个阶段都必须有游戏。

## 读完整卡再决定

索引中的主年龄不是统一能力标准。核对 JSON 卡的 ageReason、evidence、issue、change、support、observe、comment 与 source；GAME-N01—N08 的 Markdown 卡以年龄依据、原文与缺失、本次设计、教师支持和观察调整承载同类信息。判断规则负担、儿童能作哪些决定、材料与空间能否满足、来源实际展示了什么。跨年龄借用时明确简化或增加什么经验，并说明依据；小班卡片不自动扩大本技能的默认年龄范围。

- **可选试用**：保留有价值的玩法，仍须检查本班条件。这不是课堂效果已验证。
- **调整后试用**：把 change 中的适用调整实际写进材料、规则或教师支持；不能只在脚注写“注意安全”。若关键调整无法落实，则不采用该候选。
- **待核查或暂不推荐**：见[未入选记录](games/not-selected.md)。补证、纠错并重新评审后再考虑；不为了数量纳入。

点赞、收藏与浏览量仅反映传播线索，不设置入选下限、不加质量分。评论优先看具体试做困难、作者材料说明与实施后反馈；求资料、赞许表情、准备试试和平台ＡＩ回复不能当成已实施好评。低互动帖子同样按玩法、适龄性与证据审查。

## 转化为本课活动

保留原帖中可确认的做法，明确本次改编。在实施部分写清材料与空间、儿童实际行动、教师支持、观察重点及后续调整条件；儿童应有选择、尝试、修改或表达的机会。不要把失误、动作慢、拒绝身体接触或需要帮助解释为品德问题。

同一种游戏可以支持不同经验，但价值目标必须另作判断。例如，共同控球本身不能证明平等；只有结合真实参与意愿、获得机会和相互尊重的行为，才能提供有限的观察线索。纸桥承重可支持比较方法，不因使用纸桥就自动成为富强或诚信课程。没有联系时保留为独立游戏或不选。

本库研究者提出的玩法与调整也可能需要再次改编。不要把卡片中的建议、预期观察、原作者自述或精致成品写成已发生的本班成果。

## 在 Word 中如何交代

采用条件和必要调整进入“课程实施”的相应活动，并与“课程脉络”对应；将简短来源说明放在第六部分末尾的“资料依据与设计借鉴”，写明原帖标题及链接、借鉴点、本次改编。GAME 编号和完整评审留在核查记录，不整篇复制进教师阅读稿；分类分段与溯源要求见 [来源规范](source-guide.md)。

示例：“借鉴 GAME-M09 的自然物分类与数量记录方法；本方案改为核对本班借用材料，以摆物或点记表达数量，不要求书写数字。此为待试用改编，不能据此认定计数错误就是不诚信。”是否采用这一例，取决于本班是否真的需要清点与说明记录。

试用后用真实观察回看：儿童是否主动参与、如何改变办法、哪些规则或材料造成困难、谁需要额外支持。再决定保留、调整或撤去，不以游戏完成、安静或速度快直接证明价值理解。
