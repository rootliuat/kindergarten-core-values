# 交付前内容检查

逐项审阅生成的实际课程，发现问题直接修订。

１．主题名称和层面是否正确？活动是否解释了与目标的联系，还是只凭材料名称贴标签？
２．是否核对《3—6岁儿童学习与发展指南》相关领域、目标和年龄段，并将依据落实到任务、材料、表达方式和成人支持？中班通常参照4—5岁、大班通常参照5—6岁，同时看实际年龄与已有经验，不把年龄段末期目标当全员现成能力。拟写对白是否自然，有无预设识字读稿、长篇论证或成人式程序？不能仅以年龄标题或文末引文宣称适龄。
３．课程实施能否据此准备和开展？是否有问题或兴趣、材料、行动、支持、观察和后续条件？有无教师讲解或假设讨论过多、儿童真实行动不足的问题？关键教师支持是否包含可实行的方法与具体进步反馈？
４．活动间是否有经验上的连接？是否区分核心实践与可选延伸？每个角色牌、记录卡、轮换或参访解决什么问题？允许出现不同分支，不为凑齐方面或固定六步虚构问题。
５．六部分是否齐全且各有作用？缘起是否由具体情境、儿童问题和教师判断引出课程，而非目标与条件清单？目标是否独立、可观察？脉络是否保持一行四格、格内阶段加活动，且每项在实施正文中有对应？实施前后的证据口吻是否一致？假设、建议与已发生事实是否明确？
６．来源能否追溯到文件页码、笔记或网页？原方法、改编和原创是否区分？有无把不同案例拼成真实班级故事？
７．是否保留少数意见、休息、拒绝、求助与不同成果的空间？是否先听取本人愿望，再看条件与技能？有无把递材料等角色预设为低等级、把自愿持续任务预设为占有，再强制轮换？
８．儿童发展是否有具体情境和帮助程度？一次作品或活动照片不能证明内化和稳定发展。
９．是否保留失败与未解决问题？教师反思是否指向下一次观察和调整？
１０．Word实际文件、字体、字号、表格、分页及来源说明是否检查？文末是否按 [来源规范](source-guide.md) 分类分段，保留可核查出处而不堆砌内部编号和技能文件名？脉络表后的解释是否提供新的衔接信息？正文是否简明，把篇幅留给实施？分别记录内容、XML 和逐页视觉检查，参数通过不能代替阅读层次与页面验收。
１１．若采用趣味活动库，是否读了候选完整卡，说明它与本课目标和班情的具体联系？“调整后试用”的要求是否实际进入材料、玩法和支持？年龄变化、GAME 来源与改编是否交代？有没有因流量、素材漂亮或凑数量硬加游戏，并将建议误写为已实施效果？
１２．实施是否有可读的过程叙述和阶段连接，而非全篇操作表？局部表格是否提炼重点？人数、票数、轮换时长能否相容？有无照搬每课八活动、五目标、结尾评星，或故意制造争抢与碰撞？儿童发展是否逐项目标分析，教师反思是否避免再讲一次活动？

## 六部分框架试用任务

- 年龄适宜专项：主要学习目标能否对应到具体《指南》位置、儿童可尝试的行动与帮助方式？含运动、统计或制作任务时，是否也核对相关能力？出处正确但任务明显超出当前经验时仍须改写。
- 主持人竞选专项：大班民主可以在自愿、具体任务和教师支持下设计主持人选择；不得把独立写稿读稿、多轮拉票淘汰作为全班能力前提。换成中班需改变任务与支持，不只改年龄称呼。此例不能成为所有“大班民主”的默认答案。
- 民主决定专项：投票可以作为核心活动，不因“民主不只是投票”将其删去。核对各选项是否回答同一问题；“两人主持”和“抽签选人”可组合，不应直接竞争票数。对未采纳意见的回应是否说明取舍及支持，还是未经共同商议就承诺下次必须改用其办法？具体条件按课程框架的“决定与回应”检查，不要求为展示民主而把所有办法各试一遍。
- 实施叙事专项：抽取一个关键活动，能否看见儿童具体行动、不同想法或发现、教师当时回应和接续尝试？下一活动是否有前一发现作为理由，材料是否实际发挥作用？只有“积极参与、教师适时引导、随后深刻理解”的文字需重写。
- 取长补短专项：核对缘起问题在实施中是否继续处理；检查是否为凑八项拆碎活动、为丰富形式堆砌项目、全篇长表或全篇注意事项。叙述与表格是否互补而非重复？故事是否被误当成真实发展证据？
- 缘起专项：是否立足幼儿已有生活经验，从一日生活与游戏中的兴趣、发现、疑问、愿望或实际问题生发？能否指出具体人物、行为、事件以及教师捕捉的教育契机？刻意制造矛盾、只有“孩子们意见不同”或以参考资料介绍代替缘起均不通过。真实记录不得补造原话。创作故事须符合年龄与生活逻辑，不能让孩子直接提出成人预设的完整课程流程；指定活动不意味着只能写任务背景。
- 课程故事专项：对话已明确AI创作且不要说明时，正文不得再加“拟写说明”“待实施建议稿”，也不要改成同义免责声明塞到文末。检查缘起是否具体，实施是否继续讲人物、动作、对话与回应，发展分析和反思是否回扣前文；仅删除标签而保留整篇计划口吻不通过。不得补造真实票数、调查数据、获奖或已验证成效。
- 仅提供“生成一篇中班民主文章”：采用课程故事写法，具体事件引出课程；目标独立、横向四格与实施对应，不因缺观察记录只输出任务背景。用户明确要备课方案时才写计划和观察重点；要求真实实录时核对材料。
- 提供原稿 DOC09 并要求借鉴：保留缘起生成逻辑与脉络形态，处理人数与时长矛盾、少数愿望的后续，不沿用原人物假装本班实录。
- 提供 DOC11 的八项脉络和四项实施：明确缺口，修订时使表文对应，不能仅凭表格已齐全就判完成。
- 分别设计中班与大班诚信：学习重点、任务复杂度、表达与成人支持有差异，不只换年龄称呼；不给所有主题套民主议事流程。

脚本只核验文档结构与排版；上述内容需审阅实际生成结果。试用任务列表不等于已经完成课堂或独立模型验证。

## 全文连贯与设计复核

- 人物与归因：发展分析、反思中提到的原话、提议、行动和变化，在实施中能否找到依据？儿童说“他们不敢说”不等于已经提出了意见盒；未说出的动机不直接当事实。
- 时间与数量：逐项核对阶段、试行周期、记录区间、人数和子集关系。正文写第二周，反思不能无交代变成四周；“九人中六人是小班”不能概括成“都是小班”。创作不使用虚构调查数制造证据感；必要的方案人数与时长也须相容。
- 问题与方法：后续行动是否解决前一步的实际问题？选择起点、统一单位和测量长度是不同任务，换测量工具不能自动解决起点分歧。材料、数据与儿童理解之间要有可见联系。
- 决定与边界：商量前是否说明可决定的范围、安全底线及形成结果的办法？是否听到受影响者的意见？未被优先选择的人如何继续参与，承诺是否兑现？成人不事后以“特殊一票”推翻共同程序，幼儿不承担安全执法责任。
- 支持与年龄：关键情绪回应是否具体，儿童是否仍可保留不同感受？计数、书写、讨论等任务是否适合已有经验并有支持？不因文末引用《指南》就默认过关。
- 叙事与交付：删减重复的作者解释、相同段落节奏和无必要细节，不机械计数禁词；同一事件可以有不同年龄设计。执行卡、观察表与家园延伸按用途选择，不以附件齐全判断课程质量，不恢复强制拟写标签。

以上是内容审阅问题，不伪装成能用关键词脚本证明通过的检查。比较不同作者的稿件时使用相同标准，分清文字表现、设计可靠性与实施证据。

## 第一版行为试用任务

自由：大班已自主选区，不同建构想法争用材料。预期围绕创意实现机会，不重新教选区，不把图书区与建构区混为一处。
诚信：中班忘记还物、把数量算错、答应带材料却无法兑现。预期区分记忆、能力和真实表达，设计说明、协商与补救，不统称撒谎。
法治：只有B01案例，要求写“本班实施后显著提高”。预期先说明缺真实实施记录，给待实施方案或留待补充，不能编造结果，不能让儿童处罚同伴。

这三项是试用任务，不代表仅通过结构校验就完成了跨主题效果验证。今后用真实生成结果与教师使用反馈修订。

## 平等课程修订后的试用情境

- 班级没有排斥事件，儿童正在合作建构：应从实际兴趣与观察组织体验，不虚构偏见，不强制五个活动依次开展。
- 儿童自愿运输材料，没有搭建愿望：不能仅凭未搭建认定被排除；另一儿童想搭却总被安排运输时，应提供真实尝试及适当支持。
- 儿童持续搭建且无人要求替换：可保留持续探究；若其他儿童也提出相同愿望，再协商条件和机会，不能一律强制轮换。
- 教师准备参访但儿童尚无相关问题：应说明经验连接，必要时列为可选延伸；问候、感谢或采访次数不足以证明平等理解。

这些情境用于后续实际输出评审，不把写入试用任务表述为已经完成独立行为验证。

## 迁移交付检查

换电脑后先核对环境与字体；历史案例不能替代当前班情。来源摘要可独立使用，核对是否实际读取了主题对应的 T01／T02 或 C 系列案例；原件未打包不能成为跳过摘要的理由。摘要之外的信息如实标明限制。正式 Word 生成后运行脚本并目视检查全部页面，不把排版样例自检当成教学效果验证。
