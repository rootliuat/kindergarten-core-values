# Word默认交付

本包可独立生成并检查 Word；已有 docx 技能时可配合使用，不作为强制前置。首次使用先读[环境与迁移说明](portability.md)。字体采用用户指定规范；当前模板A4纵向、四边约２厘米。不要擅自缩小表格字来压页数。

| 层级 | 字体字号与格式 |
|---|---|
| 标题 | 方正小标宋简体，小二，１８磅，不加粗，居中 |
| 一级 | 黑体，三号，１６磅，不加粗；一、二、三、四、 |
| 二级 | 楷体_GB2312，三号，加粗；（一）（二）等 |
| 三级 | 仿宋_GB2312，三号，加粗；1. 2. 等，数字同字体；最多三级 |
| 正文 | 仿宋_GB2312，三号，不加粗，两端对齐，首行缩进两字符 |

一级、二级、三级标题均首行缩进两个字符；正文同样首行缩进两个字符。总标题居中，不设首行缩进。

表格首行表头与左栏项目小标题水平居中、垂直居中，无首行缩进；右栏内容正文两端对齐、首行缩进两个字符。

所有段落段前段后０磅、固定行距２８磅。正文标点采用中文格式且使用正文字体。三级标题按用户明确要求保留阿拉伯数字加点；网址本身保持有效，不替换网址标点。表格正文同字号与行距；必要时拆表，优先两列，表头重复，不拆短行。

## 生成脚本

```text
node scripts/build_word.cjs 输入.json 输出.docx
python scripts/check_word.py 输出.docx --out 核查目录
```

JSON结构：
```json
{
  "title": "社会主义核心价值观自由主题课程",
  "sections": [
    {
      "title": "一、课程缘起",
      "blocks": [
        {"text": "正文。"},
        {"level": 2, "text": "（一）课程目标"},
        {"table": [["项目", "内容"], ["材料", "具体材料。"]]},
        {"text": "来源说明", "url": "https://example.com"}
      ]
    },
    {"title": "二、课程实施", "blocks": [{"text": "具体实施内容。"}]},
    {"title": "三、儿童发展", "blocks": [{"text": "待实施方案写观察重点。"}]},
    {"title": "四、教师反思", "blocks": [{"text": "待验证问题与调整预案。"}]}
  ]
}
```

脚本只负责排版与四部分检查，不替代内容判断。长活动拆成多行，每行记录一个内容类别；过长单元格改为多个段落或独立表格。
只加载本技能目录内的固定版本 docx 库，不回退到原电脑工具目录。

可选排版字段：`titleLines` 为标题分行数组，拼接须等于 `title`，例如把主标题与副标题分开，所有行仍为小二（１８磅）、不加粗、居中；section 或文字／标题 block 可加 `pageBreakBefore: true`。通过标题起页带动后续表格，不在表格前插入空白段落。按实际篇幅安排分页，不强制每个活动一页，不为凑页数缩字。
段落 `text` 不接受换行；多个正文段落写为多个 block，表格单元格多段落使用字符串数组。表格保持两列、重复表头，短行不跨页；整行过长时拆成数个有意义的内容行。超长标题分行与段落分页由模型结合渲染结果调整，不声称脚本自动解决所有版面问题。

检查脚本先核对 DOCX XML 的字体、字号、加粗、行距、缩进、四部分、表头及左栏居中，再用独立 LibreOffice 配置生成新的 PDF，核对文字完整性、页面边界和实际字体，输出每页 PNG、总览和 check-report.json。若只运行 `--xml-only`，不能声称完成 PDF 核查。
随后查看本次报告 `image_directory` 下的页面图片，逐页目视检查表格溢出、孤立末行、标题分行、空白和字体。每次使用独立图片目录，避免误看旧稿余页。自动报告始终保留“待人工目视”状态，不能将程序通过等同于视觉通过。修改后重新生成检查当前文件；缺字体或渲染工具时如实说明缺项。最终交付可编辑 docx，PDF可供预览。
